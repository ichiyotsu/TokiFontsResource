## GoogleSans
> 请注意：这是一个家族字体，其中有非常多的分类，请注意甄别。

### GoogleSans
Google Sans 是谷歌公司官方定制并标志性的家族式几何无衬线字体（Geometric Sans-Serif）。

它是谷歌视觉身份的核心灵魂，广泛应用于 Pixel 手机系统、Android 的 Material Design 设计语言、Gmail、Google Docs、官网设计以及谷歌的各类硬件产品。

### GoogleSansVariable
这是一个谷歌官方定制字体 Google Sans 的可变字体版本。它完全支持无极变化（即在一定数值范围内进行连续、无缝的微调，而不是只能选择固定的 Light、Regular、Bold）。
