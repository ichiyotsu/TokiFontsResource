# TokiFonts For Apple
> 本分支包含了苹果字体的 .ttf 资源 正在不断更新调整中。

## PingFang
> 请注意：苹方字体针对简中和繁中做了不同版本的适配，不同版本似乎会出现字符缺失的情况，请注意辨别下载版本。

> 版本参考：PingFang 为简体中文版本 PingFangTC 为台湾繁中版本 PingFangHK 为香港繁中版本

苹方是苹果公司委托台湾的威锋数位替苹果五大操作系统（watchOS、tvOS、macOS、iOS以及iPadOS）所开发的专有字体家族。

苹方最早作为iOS 9和OS X El Capitan的默认中文字体于2015年6月8日在旧金山的WWDC 2015上公布，取代了从iOS 4和Mac OS X Leopard以来一脉相传的华文黑体系列，为现行苹果公司产品的默认中文字体。

## San Francisco Pro
San Francisco Pro (SF Pro) 是苹果公司（Apple）为其各大操作系统（如 iOS、macOS 和 iPadOS）设计的主力无衬线系统字体。
