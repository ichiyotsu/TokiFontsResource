## GoogleSans
> 请注意：这是一个家族字体，其中有非常多的分类，请注意甄别。

### GoogleSans
Google Sans 是谷歌公司官方定制并标志性的家族式几何无衬线字体（Geometric Sans-Serif）。

它是谷歌视觉身份的核心灵魂，广泛应用于 Pixel 手机系统、Android 的 Material Design 设计语言、Gmail、Google Docs、官网设计以及谷歌的各类硬件产品。

### GoogleSansVariable
这是一个谷歌官方定制字体 Google Sans 的可变字体版本。它完全支持无极变化（即在一定数值范围内进行连续、无缝的微调，而不是只能选择固定的 Light、Regular、Bold）。

### Source Han Sans (Noto Sans CJK) #思源黑体
思源黑体是Adobe与Google所合作开发的开源字型家族，属于无衬线黑体。思源黑体于2014年7月16日首次发布，覆盖繁体中文、简体中文、日文、韩文、拉丁文、希腊文和西里尔字母等文字，并提供中国大陆、台湾、香港、日本及韩国五地的汉字标准版本。字型亦提供7种字体粗细及可变字重版本，并持续更新。思源黑体的每种粗细各有65,535个字图，为OpenType技术的上限，也创下了开源字体史上的最高记录。

### Source Han Serif (Noto Serif CJK) #思源宋体
思源宋体于2017年4月3日发布，是对应于思源黑体的宋体（明体）字体，支持四种不同的东亚语言（简体中文、繁体中文、日文和韩文），且各有7级字重，其中的每一种都有65535个字形，可共同呈现一致的视觉美感。Adobe与Google发布思源黑体及思源宋体是为了呼应统一设计的需求，以服务于东亚15亿人口，并依照当地语系国家的标准规范，如日文采用日本JIS X 0208及JIS X 0213、韩文采用KS X 1001及KS X 1002标准、繁体中文支持Big5并根据中华民国教育部国字标准字体造字、简体中文以中华人民共和国的GB 18030及通用规范汉字表规范制作。
