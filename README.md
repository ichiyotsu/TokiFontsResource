## Shanghai Modeng
上海摩登体以现代字库技术为基底，突破传统汉字结构，将装饰艺术风格的几何美学精髓注入汉字骨骼。其笔形系统尝试革新——直线与圆弧的精密组合取代传统书写的自然笔触，笔画粗细均衡、刚柔相济，字体架构采用字面高耸的设计，犹如建筑般挺拔有力，在静态的几何秩序中迸发出向上的动感，使得每个字的结构充满了先锋性和想象力。
