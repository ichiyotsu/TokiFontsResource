> 本分支包含了三星字体的 .ttf 资源 正在不断更新调整中。

## Samsung Sans
SamsungSans是三星电子为其 Galaxy 系列移动设备推出的一款官方定制无衬线（Sans-serif）字体。它旨在为用户提供一种兼具美感、个性和高可读性的视觉体验

## Samsung One
SamsungOne是三星于2016年7月22日（美国时间）发布的一款专有通用字体。它是一款全球通用字体，包含26种书写系统、400多种语言和超过25000个字符。

从One UI 2开始，您可以通过 Samsung Foundation 更新应用该字体，无需下载单独的应用程序。三星 SSD 管理程序 Samsung Magician 默认应用了该字体。自 2023 年 9 月 1 日起，Galaxy 应用商店将停止提供新字体下载，仅允许重新下载已下载的字体。从 2024 年开始，所有预装One UI 6的产品都将默认使用新字体One UI Sans，取代 Samsung One 字体，不再是过去七年来三星 Galaxy 生态系统的标志性字体。

## Samsung Sharp Sans
主要用于三星的品牌标识（Logo）、广告营销以及产品包装上的标题字体，视觉上更加硬朗和现代。

## One UI Sans (Updating)
OneUISans是三星电子专门为其设备生态系统开发的定制无衬线字体该字体于 2023 年底随One UI 6.0 (Android 14)的发布在全球范围内推出，取代了长期使用的“SamsungOne”和谷歌的标准“Roboto”，成为 Galaxy 智能手机、平板电脑和可穿戴设备的默认系统字体。

## Breeze Sans (Updating)
由 Dalton Maag 设计公司为三星定制的另一个分支，主要用于三星的智能手表等可穿戴设备系统（如早期的 Tizen 或 One UI Watch 平台，现已完全停止分发）。
