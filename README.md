# TokiFonts For Corporate
> 本分支包含了其他公司品牌字体的资源 正在不断更新调整中。

## Microsoft YaHei
微软雅黑是美国微软公司委托中国方正集团设计的一款支持 ClearType 技术的字体。

## Porsche Next
Porsche Next 是保时捷官方开发的全局品牌无衬线定制字体，用于统一其数字平台和设计系统中的视觉语言。

## Adobe FangSong Std
Adobe 仿宋 Std 是 Adobe 公司推出的一款高品质的简体中文仿宋字体制品。

## HarmonyOS Sans
HarmonyOS Sans 是一款无衬线字体，它没有额外的装饰笔画，结构更加简洁清晰，在 UI 界面上具有更良好的屏幕显示效果，并且能带来更高阅读效率。HarmonyOS Sans 在字体设计上考虑了多元的应用场景，优化字形显示的灰度效果，以达到在多端的应用场景下拥有一致的体验效果。

## MiSans
MiSans Global 是由小米主导，联合蒙纳字库、汉仪字库共同打造的全球语言字体定制项目。这是一个庞大的字体家族，涵盖 20 多种书写系统，支持 600 多种语言，字符数量超过 10 万个。作为 Xiaomi HyperOS 系统默认字体，我们以简约/清晰，人文/易读，统一的视觉风格为基本原则出发，构建多语言信息体验一致性，旨在帮助为 Xiaomi HyperOS 提供互联的通用体验。

> 目前我们的字体库仅支持中文版本。
